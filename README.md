# 달의 기록 — 모바일 다이어리 PWA

흐릿한 기록은 또렷한 기억보다 더 가치 있다.

서비스가 종료된 안드로이드 캘린더·다이어리 앱 **‘달의 기록’**의 감성과 기능을 브라우저에서 그대로 쓸 수 있도록 다시 만든 개인용 웹앱입니다. 설치 없이 홈 화면에 추가해 앱처럼 쓸 수 있고, 기록은 이 기기 브라우저(IndexedDB + localStorage)에만 저장됩니다.

## 폴더 구성

```
index.html              앱 화면
manifest.webmanifest    PWA 매니페스트 (상대 경로)
sw.js                   서비스 워커 (오프라인 캐시)
css/style.css           디자인 (라이트/다크, 한지 톤)
js/                     앱 코드 (ES 모듈)
  main.js               진입점·라우터·하단 탭
  lunar.js              한국천문연구원 음력 데이터(1900~2049) 기반 음양력 변환
  holidays.js           공휴일·대체공휴일·선거일
  repeat.js             반복 일정 계산(양력·음력)
  store.js              IndexedDB + localStorage 저장, 사진 리사이징, JSON 백업
  ui.js                 시트·사진 뷰어·기록 카드·달 위상
  views/                월간·일간·작성·검색·디데이·설정·온보딩
fonts/                  Pretendard, 나눔명조 (오프라인 포함)
icons/                  앱 아이콘 (192/512/maskable/애플터치/파비콘)
```

## 단일 HTML 파일판 (파일 하나로 실행)

`file://` · `content://` 처럼 모듈·외부 파일을 못 읽는 환경에서도 열리도록, 앱 전체를 자급자족 HTML 한 개로 묶을 수 있습니다.

```
python3 tools/build-single-file.py        # 기본 출력: downloads/달의기록.html (약 180KB)
```

- **ES 모듈 제거**: `js/` 의 모든 모듈을 의존성 순서로 하나의 일반 `<script>` 안에 넣고, 작은 모듈 레지스트리(IIFE)로 `import`/`export` 를 대체합니다. `type="module"` 은 쓰지 않습니다.
- **폰트**: 웹폰트(`@font-face`)는 넣지 않습니다. 나눔명조·프리텐다드를 data URI 로 넣으면 1.3MB 를 넘고, `url(../fonts/...)` 는 로컬에서 404 가 됩니다. 대신 시스템 폰트 폴백(`Noto Serif KR`/`Batang`/`serif`, `Noto Sans KR`/`system-ui`)에 맡깁니다.
- **CSS/아이콘**: `css/style.css` 는 `<style>` 로 인라인, manifest·아이콘 링크는 제거하고 파비콘만 data URI 로 넣습니다.
- **서비스 워커**: `http:`/`https:` 에서만 등록하고, 단일 파일판(`window.__MOON_SINGLE_FILE__`)에서는 시도하지 않습니다.
- **저장 폴백**: IndexedDB → localStorage → 메모리 순. 둘 다 막힌 환경(content:// 등)에서는 시작할 때 ‘임시 모드’ 안내를 띄우고, 설정 → 백업 내보내기로 파일에 남길 수 있게 합니다.

검증(헤드리스 크롬으로 `file://` 직접 열기, 콘솔 에러 0건 포함 30여 항목):

```
pip install playwright && python3 -m playwright install chromium
python3 tools/verify-single-file.py       # 모든 검증 통과 시 종료 코드 0
```

## GitHub Pages 배포

모든 경로가 상대 경로(`./`)라서 **하위 경로(`/moon-record/`)와 루트(`/`) 모두** 그대로 동작합니다.

1. 이 폴더의 **내용물**을 저장소에 올립니다.
   - `https://<아이디>.github.io/moon-record/` 로 열고 싶다면: 저장소 이름을 `moon-record`로 만들고 이 폴더 내용을 저장소 루트에 push
   - `https://<아이디>.github.io/` 로 열고 싶다면: `<아이디>.github.io` 저장소 루트에 push
2. 저장소 → Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
3. 1~2분 뒤 주소로 접속합니다.
4. 안드로이드 크롬에서 접속 → ⋮ 메뉴 → **홈 화면에 추가** (설정 화면의 ‘홈 화면에 추가’에서도 안내)

> 파일을 수정해 다시 올릴 때는 `sw.js`의 `VERSION` 값을 올려 주세요. 그래야 기기에 남은 옛 캐시가 교체됩니다.

## 기능

- **월간 / 일간**: 음력 표시, 주말·공휴일 색, 기록 칸(색+모양 칩), 디데이 표시, 좌우 스와이프로 달·날짜 이동
- **기록**: 일정 / 일기 / 통합 기록, 시간, 장소, 태그, 색 6종 × 모양 8종, 본문, 사진 여러 장(자동 리사이즈·썸네일), 체크리스트(진행률)
- **반복**: 매일·매주·매월·매년, 간격, 요일 지정, 종료일, **음력 매년 반복**(음력 생일·기념일). 반복 기록은 ‘이 날짜만 삭제’도 가능
- **디데이**: 다가오는 날/지나온 날, 양력·음력 기준 매년 반복
- **검색**: 제목·본문·태그·장소·체크리스트 실시간 통합 검색, 종류 필터
- **설정**: 테마(자동/라이트/다크), 테마 색, 글자 크기, 캘린더 글씨 크기, 주 시작 요일, 음력·격자선·공휴일 이름 표시, 일간 화면 표시 방식(카드/간결/타임라인), 좌우명·명언, JSON 백업(사진 포함/데이터만)·복원, 저장 공간 확인
- **오프라인**: 첫 방문 후에는 인터넷 없이 실행·열람 가능

## 데이터에 대해

- 기록·사진·설정은 **이 브라우저에만** 저장됩니다. 서버로 전송되지 않습니다.
- 브라우저 데이터를 지우면 기록도 사라지므로, 가끔 **설정 → 백업 내보내기**로 JSON 파일을 받아 두세요.
- 음력 변환은 한국천문연구원(KARI) 음력 데이터(1900~2049년)를 내장해 오프라인에서도 정확히 계산합니다.
- 공휴일은 양력·음력 공휴일과 대체공휴일 규칙으로 계산하며, 2026년 개정으로 공휴일이 된 노동절·제헌절도 포함합니다. 임시공휴일은 포함하지 않습니다.
